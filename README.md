## 🎮 게임 소개

**7Days**는 난파된 배에서 선원들과 함께 7일간 생존해야 하는 2D 서바이벌 게임입니다.

플레이어는 매일 바다 속으로 잠수하여 물고기와 자원을 채집하고, 한정된 자원을 선원들에게 분배하며 모두의 생존을 이끌어야 합니다. 배고픔, 갈증, 체온을 관리하고, 노후화되는 배를 수리하며 살아남으세요.

## ⭐ 주요 기능 및 콘텐츠

### 🌅 Day Cycle 시스템
- **아침(Morning)**: 선원과 배의 상태를 확인하고 하루를 준비합니다.
- **잠수(Diving)**: 수중으로 잠수하여 물고기를 사냥하고 자원을 수집합니다.
- **저녁(Evening)**: 수집한 자원을 선원들에게 분배하고 다음 날을 대비합니다.

### 🎯 작살 사냥 시스템
- 차지 기반 작살 발사 메커니즘
- 물고기별 QTE 포획 미니게임
- 다양한 어종과 난이도별 보상

### 👥 선원 관리
- 3가지 생존 수치 관리: 배고픔 / 갈증 / 체온
- 드래그 앤 드롭 자원 분배 UI
- 선원별 상태 모니터링 및 위기 알림

### 🛠️ 배 유지보수
- 매일 노후화되는 배 HP
- 목재를 사용한 수리 시스템
- 배 파괴 시 게임 오버

### 🐟 다양한 해양 생물
- 일반 물고기: 복어, 블루탱, 니모, 거북이 등
- 고급 물고기: 돌상어, 청새치, 그루퍼
- 위험 생물: 상어, 범고래, 해파리
